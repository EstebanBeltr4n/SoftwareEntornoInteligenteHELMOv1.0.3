# Changelog

Todos los cambios relevantes de este proyecto serán documentados en este archivo. El formato adopta la convención de Keep a Changelog y se utiliza como registro legible por humanos del avance técnico y documental del sistema HELMO.[web:321][web:322][web:335]

## [Unreleased]

### Added
- Estructura documental base del repositorio para soporte de derechos de autor, incluyendo carpetas de `docs`, `hardware`, `firmware`, `integrations/ttn` y `legal`.[cite:1]
- Documentos generales del sistema: descripción, arquitectura, instalación de entorno, manual técnico y evidencias para registro.[cite:1]
- Documentación legal complementaria del repositorio: autoría, titularidad, versión declarada y alcance documental.[cite:1]
- Documentación modular para nodos dedicados de pH, turbidez y nivel, incluyendo archivos `.ino`, `README.md`, especificaciones funcionales y payloads.[cite:45]
- Estructura base de `hardware/` con subcarpetas para diagramas, pinout, listas de materiales, calibración, ensamble, referencias y versiones.[cite:1]
- Plantillas y guía de documentación para la carpeta de hardware del proyecto.[cite:1]

### Changed
- Se consolidó la organización del repositorio para presentar HELMO como obra técnica integral con componentes de firmware, backend, hardware, documentación y soporte legal.[cite:45]
- Se fortaleció la lectura del sistema como solución de monitoreo hídrico distribuido con proyección SaaS y arquitectura centralizada de servicios web y datos.[file:308][cite:45]

### Security
- Las credenciales y datos sensibles utilizados en firmware documental fueron neutralizados o reemplazados por valores nulos en los archivos preparados para soporte de derechos de autor.[cite:1]
