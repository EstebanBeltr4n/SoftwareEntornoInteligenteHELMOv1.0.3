# Uso de la carpeta include - Nodo de turbidez HELMO

La carpeta `include/` del módulo `firmware/nodo_turbidez` está destinada a encabezados del proyecto, tales como constantes de calibración, prototipos de funciones, configuración de pines y estructuras compartidas. Esta organización favorece la modularidad del firmware y resulta adecuada para una evolución futura del nodo hacia una base de código con múltiples archivos fuente.[cite:1]

En versiones posteriores, esta carpeta puede alojar archivos como:

- `turbidity_config.h`
- `pins.h`
- `payload_turbidity.h`
- `adc_utils.h`

Documentar desde ahora el propósito de `include/` ayuda a mantener una presentación ordenada y profesional del repositorio del proyecto HELMO.[cite:1]
